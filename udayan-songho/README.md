# উদয়ন সংঘ — ওয়েবসাইট

এই ফোল্ডারে আপনার ক্লাবের সম্পূর্ণ ওয়েবসাইট আছে:

```
udayan-songho/
├── index.html      → মূল পাতা (সব সেকশন এখানে)
├── css/style.css   → ডিজাইন, রং, ফন্ট
├── js/script.js    → কাউন্টডাউন, গ্যালারি, মেনু ইত্যাদি
└── README.md       → এই ফাইল
```

## কীভাবে দেখবেন
`index.html` ফাইলে ডাবল-ক্লিক করলেই যেকোনো ব্রাউজারে (Chrome/Firefox) সাইটটি খুলে যাবে। ইন্টারনেট চালু থাকতে হবে, কারণ ফন্ট আর আইকন অনলাইন থেকে আসে।

## যা যা বদলাতে হবে (আপনার নিজের তথ্য দিয়ে)

1. **আসল ছবি বসানো** — `js/script.js` ফাইলে `galleryData` অংশে প্রতিটি ছবির `src` লিংক আছে (এখন placeholder ছবি বসানো আছে)। নিজের ছবি ব্যবহার করতে:
   - ছবিগুলো `images/` নামে একটা ফোল্ডার বানিয়ে তার ভেতর রাখুন
   - `src: 'https://picsum.photos/...'` এর জায়গায় লিখুন `src: 'images/আপনার-ছবি.jpg'`
   - `year` আর `caption` ইচ্ছেমতো বদলে দিন

2. **প্রতিষ্ঠার সাল, সংখ্যা, ইতিহাস** — `index.html`-এ "আমাদের কথা" ও "আমাদের পথচলা" অংশে এখন নমুনা তথ্য (১৯৯০ সাল ইত্যাদি) দেওয়া আছে। আপনার ক্লাবের আসল ইতিহাস দিয়ে বদলে নিন।

3. **কমিটির নাম** — "কার্যকরী কমিটি" অংশে নমুনা নাম আছে, আসল সদস্যদের নাম ও পদ দিয়ে বদলান।

4. **ঠিকানা, ফোন, ইমেইল, সোশ্যাল মিডিয়া লিংক** — "যোগাযোগ" অংশে `[পাড়ার নাম]`, `[শহর]` ইত্যাদি জায়গায় আসল তথ্য বসান। Facebook/Instagram/YouTube/WhatsApp-এর `href="#"` জায়গায় আসল লিংক বসান।

5. **এই বছরের পুজোর সময়সূচি** — "এই বছরের পুজো" অংশে সময় বদলাতে পারেন। কালীপুজো ২০২৬-এর তারিখ (৮ নভেম্বর) ও আনুমানিক নিশীথ কাল অনুযায়ী কাউন্টডাউন বসানো আছে (`js/script.js`-এ `target` ভ্যারিয়েবল) — পঞ্জিকা অনুযায়ী প্রয়োজনে সময়টা মিলিয়ে নেবেন।

## ইন্টারনেটে প্রকাশ করবেন কীভাবে
